## Global hotkeys

In addition to the predefined shortcuts below, you can configure two custom global hotkeys that will also work
when Sonto is in the background. You can use these hotkeys to add a new task to your inbox, or to today. 
Configure these hotkeys in Settings &rarr; Tasks.

## General

| Key                           | Description                     |
|-------------------------------|---------------------------------|
| <kbd>spacebar</kbd> or <kbd>Cmd</kbd> + <kbd>N</kbd> | New task (on the current screen) |
| <kbd>Cmd</kbd> + <kbd>\\</kbd> | Jump to any screen in the app or search tasks |
| <kbd>Cmd</kbd> + <kbd>1</kbd> | Jump to inbox |
| <kbd>Cmd</kbd> + <kbd>2</kbd> | Jump to day |
| <kbd>Cmd</kbd> + <kbd>3</kbd> | Jump to week |
| <kbd>&darr;</kbd> / <kbd>&uarr;</kbd> | Navigate task lists |
| <kbd>Alt</kbd> + <kbd>&darr;</kbd> / <kbd>&uarr;</kbd> | Jump to bottom / top of task list |
| <kbd>Shift</kbd> + <kbd>&darr;</kbd> / <kbd>&uarr;</kbd> | Select downward / upward in task list |
| <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>&darr;</kbd> / <kbd>&uarr;</kbd> | Select all downward / upward in task list |
| <kbd>&larr;</kbd> / <kbd>&rarr;</kbd> | Navigate weekdays on the week screen |
| <kbd>Cmd</kbd> + <kbd>Ctrl</kbd> + <kbd>N</kbd> | Open current screen in new window |

## On day or week screens

| Key                           | Description                     |
|-------------------------------|---------------------------------|
| <kbd>Cmd</kbd> + <kbd>B</kbd> | Plan the current day or week |
| <kbd>Cmd</kbd> + <kbd>&larr;</kbd> | Go back one day or week |
| <kbd>Cmd</kbd> + <kbd>&rarr;</kbd> | Go forward one day or week |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>&larr;</kbd> | Go to the current day or week |


## With selected tasks

| Key                           | Description                     |
|-------------------------------|---------------------------------|
| <kbd>Return</kbd> | Toggle editing the task |
| <kbd>Cmd</kbd> + <kbd>.</kbd> | Open task in focus view (full screen editing) |
| <kbd>Cmd</kbd> + <kbd>G</kbd> | Open task in floating panel (handy for tasks on week screen) |
| <kbd>Cmd</kbd> + <kbd>D</kbd> | Move tasks to another list |
| <kbd>Cmd</kbd> + <kbd>&uarr;</kbd> / <kbd>&darr;</kbd> | Move task up / down one place |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>&uarr;</kbd> / <kbd>&darr;</kbd> | Move task to top / bottom |
| <kbd>Cmd</kbd> + <kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> | Copy / cut / paste tasks |
| <kbd>Cmd</kbd> + <kbd>S</kbd> | Schedule tasks |
| <kbd>Cmd</kbd> + <kbd>Y</kbd> | Quick schedule for today |
| <kbd>Cmd</kbd> + <kbd>U</kbd> | Quick schedule for tomorrow |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>U</kbd> | Quick schedule for next monday |
| <kbd>Cmd</kbd> + <kbd>I</kbd> | Quick schedule for this week |
| <kbd>Cmd</kbd> + <kbd>O</kbd> | Quick schedule for next week |
| <kbd>Cmd</kbd> + <kbd>P</kbd> | Quick unschedule |
| <kbd>Cmd</kbd> + <kbd>F</kbd> | Automatically find time on your calendar, respecting other commitments and working hours |
| <kbd>Cmd</kbd> + <kbd>E</kbd> | Toggle completion |
| <kbd>Cmd</kbd> + <kbd>R</kbd> | Toggle in-progress |
| <kbd>Cmd</kbd> + <kbd>T</kbd> | Toggle priority |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>T</kbd> | Assign tags |
| <kbd>Cmd</kbd> + <kbd>K</kbd> | Go to scheduling of task (day or week) |
| <kbd>Cmd</kbd> + <kbd>L</kbd> | Go to categorisation of task (project or area)  |

<Info>
  Moving and reordering works on the inbox, day, week, project, area and tag screens — the ones you
  arrange yourself. It's unavailable while you're editing a task, since
  <kbd>Cmd</kbd> + <kbd>&uarr;</kbd> and <kbd>Cmd</kbd> + <kbd>&darr;</kbd> then belong to the text
  field. See [Reordering tasks](/reference/tasks#reordering-tasks).
</Info>

## When editing notes

You can insert checklist items (which you can also check off), and apply basic text formatting. To add a checklist item, just type `[]`. You can also indent them to create nested lists.

| Key                           | Description                     |
|-------------------------------|---------------------------------|
| Type `[]` | Insert checklist item |
| <kbd>Cmd</kbd> + <kbd>]</kbd> | Indent checklist item |
| <kbd>Cmd</kbd> + <kbd>[</kbd> | Unindent checklist item |
| <kbd>Cmd</kbd> + <kbd>Return</kbd> | Toggle checklist item |
| <kbd>Cmd</kbd> + <kbd>B</kbd> | Toggle bold on selection |
| <kbd>Cmd</kbd> + <kbd>I</kbd> | Toggle italic on selection |

## Hovering over calendar event

| Key                           | Description                     |
|-------------------------------|---------------------------------|
| <kbd>Cmd</kbd> + <kbd>J</kbd> | Join video call (if attached to the event) |

## Availability

Keyboard shortcuts are a **Mac** feature. On iPhone and iPad, the same actions live in a task's `…`
menu and the action bar. If you use VoiceOver, every row also carries move, schedule, complete and
delete actions — see [Accessibility](/reference/accessibility).
