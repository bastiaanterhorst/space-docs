Most issues have a quick fix. Find the topic below; if you're still stuck, get in touch and we'll help.

## Syncing between devices

If changes aren't appearing on another device, work through the dedicated guide — it covers iCloud
accounts, sync status, and a few deeper fixes. See [Sync troubleshooting](/reference/sync-troubleshooting).

## A calendar isn't showing up

Sonto uses the calendar accounts on your Mac or iPhone. If a calendar is missing, add or enable the
account in your device's system settings — Sonto picks it up automatically. See
[Calendar](/reference/calendar).

## The Share extension isn't there (Mac)

On Mac the Share extension has to be enabled once before it appears in Share menus. See
[Share extension](/reference/other-topics/share-extension).

## An AI tool won't connect

Check that the MCP server is set up and that you're using the right command for your tool. See
[Connect to AI Agents](/reference/ai-with-mcp).

## I lost a task or project

If you deleted something or it's gone missing, you can restore it from a backup — restoring only ever
**adds**, so it can't make things worse. See [Backup & Import](/reference/manage-data).

## Sonto won't update

Sonto 2.0 needs **macOS 26, iOS 26 or iPadOS 26 or later**. Below that, the App Store won't offer you
the update and your existing version carries on working. See
[System requirements](/reference/system-requirements).

## Still stuck?

Email <a href="mailto:support@sonto.app">support@sonto.app</a>. It helps to include your OS
version, your Sonto version and build number (Mac: **Sonto → About Sonto**), and a short description of
what you're seeing.
